## Разработка
- Создан проект и подключен DRF
- Созданы модели для  users , courses и lessons в приложении lms
- Описаны модели CRUD для course (Viewsets) и lesson (Generic) 
- для модели курса добавлен в сериализатор поле вывода количества уроков
- добавлен payment в модель приложения users
- созданы фикстуры для добавления данных пользователей по платежам
- настроены следующие фильтры и сортировки в платежах (payment):
  1.возможность менять порядок сортировки по дате оплаты,
  2.фильтрация по курсу или уроку,
  3.фильтрация по способу оплаты.
- реализован CRUD для пользователей
- настроено использование JWT-авторизации
- заведена группа модераторов
- настроены права доступов для модераторов и владельцев
